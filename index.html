🔐 GitHub 저장소 연결 설정 (눌러서 열기 · 평소에는 숨김)
비공개 저장소를 먼저 생성하세요. Fine-grained personal access token은 해당 저장소에 Contents: Read and write 권한이 필요합니다. 토큰은 GitHub Pages 코드에 넣지 않고 이 기기의 브라우저에만 저장합니다. 기기를 공유한다면 토큰이 노출될 수 있습니다.

동일한 GitHub 계정·저장소·토큰을 PC와 모바일에 각각 한 번씩 입력하세요. 동시에 편집하면 충돌이 발생할 수 있어 수동 확인이 필요합니다.
